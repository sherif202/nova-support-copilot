Where I'd adjust your model

“% of conversations resolved without a human”

Better rule: count a chat only when the customer confirms it was solved and doesn't contact us again within 7 days. A customer who gives up also looks “resolved without a human”.

“Retrieval (RAG) design: chunking, embeddings”

Better rule: choose retrieval by the content. Nova's 68 short rules fit in the prompt, and bank records need exact matches. Add a vector store only when long documents make that necessary.

“hallucination rate”

Better rule: you can't count what nobody noticed. Measure groundedness on a test set, then sample live answers and track confirmed cases.

Quality bars

Definition of Ready

  • User, goal and value are clear
  • Passes INVEST, at 8 points or fewer
  • Acceptance criteria are written
  • AI behaviour names a test set and threshold
  • Data sources and owners are known
  • Compliance needs are flagged

Definition of Done

  • Code reviewed and merged
  • Unit tests and the release test pass
  • No gate has regressed
  • Arabic right-to-left checked
  • Logs stay masked
  • Documents and changelog updated
  • Demoed to the PM

Best practices

  • Change one thing, then run the tests
  • Never edit a test case to raise a score
  • Put what must never fail in code
  • Ship behind a feature flag
  • Keep a person one tap away
  • Pin versions, and retest before changing them
