Cost of evaluating

One full run (106 cases since 1.0.13) costs about US$0.03 (EGP 1.5) on Claude Haiku 5.5, thanks to prompt caching: about 870,000 tokens read from cache against 25,000 new ones per run. All eval, bake-off and shadow runs to date cost about US$2.21 in total. Evaluating on every change is affordable, so there is no reason to skip it.
