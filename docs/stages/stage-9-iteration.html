The weekly fix cycle

  1. Take the top 3 failures from the PM panel and the weekly quality report.
  2. Add each real chat to the golden record (reworded, never copied from the hold-out).
  3. Fix the prompt, the knowledge base, a trap row or a rule, one change at a time.
  4. Run the full eval (tools/eval.mjs, about US$0.02).
  5. Ship only if nothing else got worse and every hard gate passes; log it in the CHANGELOG.

Agents' "Wrong label?" corrections and customers' "No, not solved" answers feed step 1; a person approves each new example before the copilot learns from it.

Triggers

  • ✓Fine-tune trigger: not fired. Fine-tune only the classifier if intent accuracy stays under 90%. Today it is 96.7 to 98.3%, so prompting stays.
  • ~New model or vendor: rerun the bake-off and switch only if it passes the gates and costs no more. OpenAI and Gemini runs are scripted and waiting for keys.
  • ~Policy change: update the knowledge-base entry and its eval case together, the same day.
  • …Monthly taxonomy review: if a handed-off topic keeps growing (the PM panel's intents table), frame it with evidence before it joins the scope.

The 2-page case study (outline)

Page 1

  • Problem: 45,000 contacts a month; 27,000 are fee, dispute and card questions answerable with information.
  • Research: the interview, the AI-fit scorecard, the cost-of-being-wrong matrix (stage 1).
  • Decisions and trade-offs: 3 intents in, money moves and advice out; a workflow, not an agent; fraud in code before any AI; policies in the prompt, no vector database; Haiku over larger models.

Page 2

  • Metric and result: North Star = verified resolution rate; the eval went from DO NOT SHIP to SHIP in 12 versions with fraud recall at 100% throughout; the shadow run says 63% of 200 synthetic tickets would be resolved; cost EGP 0.024 per answer. The pilot result is still to come.
  • One failure caught and fixed: a rate-limited customer reporting fraud got "please wait"; now fraud always goes first (1.0.8).
  • What I'd do differently: write the hold-out with a second person from day one; add the LLM judge earlier; test with real phrasing before tuning.
